### Таблица коммутации VLAN для Open vSwitch (OVS)

Поскольку ваши коммутаторы работают на OVS, вот как нужно настроить VLAN'ы на портах. Предположим, что у OMS-LSW и OMS-RSW есть по 5 портов.

**OMS-LSW (Этаж 1, левое крыло)**

| Порт (Interface) | Режим (Mode) | Access VLAN | Trunk VLANs | К кому подключен |
|---|---|---|---|---|
| eth0 | Trunk | - | 10, 20, 30, 99 | OMS-LR (eth1) |
| eth1 | Trunk | - | 10, 20, 30, 99 | OMS-RR (eth1) - *Резервный путь* |
| eth2 | Access | 99 | - | PC2 (Admin) |
| eth3 | Access | 10 | - | PC1 (Staff) |
| eth4 | Access | - | - | Не используется (или в бонде) |

**OMS-RSW (Этаж 2, правое крыло)**

| Порт (Interface) | Режим (Mode) | Access VLAN | Trunk VLANs | К кому подключен |
|---|---|---|---|---|
| eth0 | Trunk | - | 10, 20, 30, 99 | OMS-RR (eth1) - *Основной путь* |
| eth1 | Access | 30 | - | OMS-WRR1 (точка доступа для гостей) |
| eth2 | Access | 20 | - | PC3 (Contractor) |
| eth3 | Trunk | - | 10, 20, 30, 99 | OMS-LR (eth2) - *Резервный путь* |
| eth4 | Access | - | - | Не используется |

*Примечание:* Для отказоустойчивости вы можете объединить порты `eth0` и `eth3` на каждом коммутаторе в бонд (Link Aggregation) к маршрутизаторам.

### Какие сети нужно создать через virsh?

Виртуальные сети в `virsh` используются для организации взаимодействия между виртуальными машинами и хостом, а также для выхода в "физическую" сеть хоста. В вашем проекте нужно создать сети, которые имитируют физическую среду передачи данных между устройствами.

Лучше всего использовать тип сети **"Isolated"** (или "NAT" с отключенным NAT) или **"Bridge"** (если вы хотите, чтобы устройства были в одной сети с вашей хост-машиной, но для проекта это не обязательно). Каждая связка "кабель" между двумя устройствами должна быть отдельной сетью.

Вот список сетей, которые нужно создать в `virsh`:

1.  **net-isp-ur** (Isolated): Для связи DomRu-ISP и OMS-UR. Подсеть 172.16.1.0/30.
2.  **net-ur-lr** (Isolated): Для связи OMS-UR и OMS-LR. Подсеть 10.0.0.0/30.
3.  **net-ur-rr** (Isolated): Для связи OMS-UR и OMS-RR. Подсеть 10.0.0.4/30.
4.  **net-lr-lsw** (Isolated): Для связи OMS-LR и OMS-LSW. Это транковый линк, но на уровне virsh это просто сеть. Настройка VLAN будет внутри коммутатора.
5.  **net-lr-rsw-reserve** (Isolated): Для резервной связи OMS-LR и OMS-RSW.
6.  **net-rr-lsw** (Isolated): Для связи OMS-RR и OMS-LSW.
7.  **net-rr-rsw** (Isolated): Для связи OMS-RR и OMS-RSW (может совпадать с net-rr-lsw, если они через один интерфейс? Уточните по схеме).
8.  **net-rr-rs1** (Isolated): Для связи OMS-RR и сервера OMS-RS1. Подсеть 10.0.99.0/24 (кусок для линка).
9.  **net-lsw-pc** (Isolated): Общая сеть для подключения PC1 и PC2 к OMS-LSW. (VLAN'ы разделят трафик позже).
10. **net-rsw-pc** (Isolated): Общая сеть для подключения PC3 и WRR1 к OMS-RSW.
