### Тема проекта: _Эксплуатация компьютерной сети центра правовой защиты населения_

## 1. Исходные данные

### 1.1 Сегменты сети

Центр эксплуатирует КС с выделенным сервером на трёх этажах здания. 
КС имеет гостевой беспроводной сегмент. 
Сотрудники имеют доступ в Интернет в кабинетах и на прилегающей территории.

Сегменты сети:

- Staff
- Admin
- Contractor
- Guest

### 1.2 ОС

Администрация отдает предпочтение системному программному обеспечению Eltex. 
На сервере установлена операционная система RedOS.
В филиале также установлен Eltex.
Создать модель сети используя виртуальное оборудование. 

Сетевая конфигурация с требованиями:

1. Организация потоков трафика согласно матрицы доступа (ACL)
2. Средства отказоустойчивости
3. Средства защиты
4. Мониторинг устройств (Zabbix)
5. Удаленное управление устройствами

### 1.3 Сетевая связность

Доступ к глобальной сети Интернет осуществляется с помощью услуг ISP Дом.ru. 
VPN используется для связи с филиалом. 

Произвести тестирование сети.
